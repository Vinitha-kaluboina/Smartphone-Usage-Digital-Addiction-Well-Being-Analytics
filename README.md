📱 Smartphone Usage, Digital Addiction & Well-Being Analytics

📌 Project Overview

Smartphone Usage, Digital Addiction & Well-Being Analytics is a data analytics project designed to analyze smartphone usage patterns and their relationship with digital addiction and personal well-being.

The project collects and analyzes factors such as daily screen time, app usage, social media usage, sleep duration, notifications, phone-checking frequency, and well-being indicators to identify usage patterns and provide meaningful insights.

The main goal is to help users understand their smartphone habits and promote healthier digital usage.

---

🎯 Objectives

- Analyze daily smartphone usage patterns.
- Identify indicators of excessive smartphone usage.
- Study the relationship between screen time and well-being.
- Analyze social media and app usage behavior.
- Examine the relationship between smartphone usage and sleep.
- Identify users with potential digital addiction indicators.
- Generate meaningful analytics and visualizations.
- Provide insights for improving digital well-being.

📈 Analysis Performed

1. Screen Time Analysis

Analyze average daily smartphone usage and identify users with high screen-time levels.

2. App Usage Analysis

Analyze which categories of applications consume the most time, such as:

- Social Media
- Entertainment
- Gaming
- Education
- Communication
- Productivity

3. Sleep Analysis

Study the relationship between smartphone usage and sleep duration.

4. Digital Addiction Analysis

Analyze behavioral indicators such as:

- Excessive screen time
- Frequent phone checking
- High notification frequency
- Excessive social media usage
- Smartphone usage before sleeping

5. Well-Being Analysis

Analyze how smartphone usage patterns are associated with indicators such as:

- Stress
- Sleep
- Physical activity
- Mood
- Overall well-being

6. Correlation Analysis

Correlation techniques can be used to examine relationships between variables such as:

Screen Time ↔ Sleep Duration
Screen Time ↔ Stress Level
Social Media Usage ↔ Well-Being
Phone Checking ↔ Stress
Physical Activity ↔ Well-Being
